# POLARIS

**AI research assistant for materials science.** LLM-powered agents for literature review, hypothesis generation, experiment design, curve fitting, ML, and perovskite phase mapping, available on web, desktop, and mobile.

| Repo | What it is |
|------|------------|
| [backend-api](https://github.com/POLARIS-Ahmadi-OFFICIAL/backend-api) | FastAPI backend: agents, watcher, MCP orchestrator, phase-mapper pipeline |
| [web-frontend](https://github.com/POLARIS-Ahmadi-OFFICIAL/web-frontend) | Next.js web app and Electron desktop app |
| [mobile-development](https://github.com/POLARIS-Ahmadi-OFFICIAL/mobile-development) | Expo / React Native mobile app |
| [shared-types](https://github.com/POLARIS-Ahmadi-OFFICIAL/shared-types) | OpenAPI contract shared by all of the above |

**New here?** Start with the [onboarding guide](https://github.com/POLARIS-Ahmadi-OFFICIAL/.github/blob/main/ONBOARDING.md) ([PDF](https://github.com/POLARIS-Ahmadi-OFFICIAL/.github/blob/main/ONBOARDING.pdf)).
